三、控标与倾向性分析（重点）

以下条款对"是否有既有服务基础"高度敏感，构成事实上的竞争壁垒。评级为对新进入者的不利程度。

星震同源蓝光存储对接 高壁垒

条款 1.4 / 1.10 要求与学校现有 星震同源蓝光光盘库 对接实现异质备份。指定既有硬件品牌，未与该系统做过接口的厂商需额外投入联调成本，且成功与否受第三方配合影响。

现有档案系统 2–3T 历史数据迁移 在位强绑定

条款(6)要求迁移现有档案系统历史数据。掌握原系统数据结构者具备决定性优势；外部厂商迁移风险与工作量不可控，是最强的在位供应商信号。

i北理（钉钉）深度集成 中高壁垒

检索/借阅/审批/实物拍照登记/待办均需嵌入 i北理钉钉端（CAS 登录）。需具备钉钉工作台开发经验与学校移动端接入资源。

CAS 单点登录 + OA/教务/资产/网站多系统对接 中高壁垒

条款(2)要求对接 OA(API)、教务(库视图)、资产(库视图)、网站(API/中间库)，并含第三方系统配合费用"由投标方自行评估"。集成费用风险转嫁给投标方，报价需预留充足集成余量。

珠海校区全宗授权 / 跨校区异地同步 产品门槛

要求多全宗、跨校区异地同步并为异地灾备预留。需成熟的多全宗/多租户产品架构，通用集成商难以短期实现。

国产化单机版（龙芯 + 银河麒麟） 产品门槛

须提供已适配龙芯 CPU + 银河麒麟 OS 的单机版档案系统（终身授权）。要求厂商具备信创版本或完成过信创适配，非普遍能力。

合规提示：上述条款多为指向既有环境的"实质性对接要求"，属采购人正当业务需求，一般难以质疑为违规控标；但客观上抬高外部厂商门槛。建议在投标答疑阶段就"星震同源接口协议""第三方系统配合责任边界""迁移数据交付形式"提出书面澄清，锁定风险责任。

六、采购方分析：北京理工大学

北理工档案信息化建设成熟，历史采购涵盖人事档案审核系统、会计档案数字化、会计凭证影像化、档案馆新馆空间改造及库房建设等（近年该校档案相关公告 28 条）。说明：

  • 采购人对档案业务规范、国档局标准熟悉，评审专业、对技术响应质量要求高，"堆参数"难以蒙混。
  • 已建成部分档案系统与配套硬件（含蓝光存储），存量环境复杂，本项目本质是"存量整合 + 升级 + 认定冲刺"，非从零新建。
  • 校方目标是通过国档局数字档案室认定（2年内），更看重厂商的认定项目经验与咨询能力，而非单纯软件功能。
制胜要点：本项目"档案咨询 + 认定辅导"权重高。能提供已通过国档局数字档案室/档案馆认定案例、并配备档案系列馆员职称咨询顾问的厂商，最契合校方诉求。

九、投标策略建议

1. 决策分流
成熟档案软件厂商（有产品+信创版+认定案例）→ 重点投；有部分能力但缺档案资质/迁移经验 → 组联合体或分包合作；纯集成商无档案产品 → 放弃，避免陷入高集成风险低毛利泥潭。
2. 澄清先行（答疑阶段务必提交）
①星震同源蓝光库接口协议与配合方；②OA/教务/资产/钉钉第三方配合责任与费用边界；③历史数据交付形式（原始库/标准中间格式）；④国档局认定的责任边界与时间节点。将风险以书面澄清固化。
3. 技术响应
对全部 ★ 项做到"逐条正面应答 + 截图/案例佐证"，杜绝废标；对 ▲ 项突出蓝光对接、四性检测、鉴定处置、钉钉集成、信创单机版等差异化能力抢分。
4. 加分锚点
主打"国档局数字档案室认定成功案例 + 高校档案客户 + 档案馆员职称咨询团队"三张牌，直击校方"通过认定"的核心诉求。
5. 报价策略
135 万含软件+集成+咨询+迁移+信创单机版+1年质保，实际可支配开发费用有限。在集成/迁移条线预留 15–25% 风险准备金；若确为在位厂商可偏高报价，若为挑战者宜以技术分取胜、价格适度进取。
